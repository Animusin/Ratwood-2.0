# Постоянные записи чейнджлога

Файлы `YYYY-MM.yml` в этой папке дополняют соответствующий месяц из `../archive/` в игровом окне.
Формат тот же: дата → автор → список изменений. `rscadd` показывает штатную зелёную галочку.

Эти файлы хранятся в Git отдельно от апстримного архива. Генератор чейнджлога их не переносит и не удаляет.
Совпадающие дата, автор, тип и текст отображаются один раз. Месяц доступен и без апстримного файла.
После изменения перезапустите сервер, чтобы обновить кэш ресурсов.
